# Ciné Mas Duc — mise en ligne de l'appli

## Fichiers à mettre en ligne (tous au même niveau)
index.html, manifest.webmanifest, sw.js, icone-192.png, icone-512.png, apple-touch-icon.png

## 1. Dépôt GitHub
Sur github.com : New repository, nom `cine-mas-duc`, Public, Create.
Puis Add file > Upload files, glisse les 6 fichiers, Commit changes.

## 2. Activer GitHub Pages
Settings > Pages > Source : Deploy from a branch > Branch : main, dossier / (root) > Save.
Après une à deux minutes, l'appli est en ligne à l'adresse :
https://TON-NOM-GITHUB.github.io/cine-mas-duc/

## 3. Installer sur le téléphone
- Android (Chrome) : ouvrir l'adresse, menu ⋮ > Ajouter à l'écran d'accueil (ou Installer l'application).
- iPhone (Safari) : ouvrir l'adresse, bouton Partager > Sur l'écran d'accueil.

## 4. Enrichir la collection (une fois)
De préférence depuis le PC, écran allumé : roue dentée > Enrichir la collection > Démarrer, code demandé.
Compter 10 à 20 minutes pour 1 165 films. On peut interrompre et reprendre.
À la fin : roue dentée > Films à vérifier affiche ceux dont la correspondance TMDB était douteuse ;
pour chacun : Modifier > Chercher un autre film TMDB > choisir le bon > Enregistrer.

## Mettre à jour l'appli plus tard
Remplacer le ou les fichiers modifiés sur GitHub (Add file > Upload files).
Sur le téléphone, la nouvelle version s'affiche à la deuxième ouverture.
